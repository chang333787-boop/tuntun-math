# 튼튼 수 다리가 하는 일 (11-05 정본)

교사 11-05: "구조는 좋은데 애들도 뭘 눌러요, 선생님들도 헷갈려요, 만드는 나도 한눈에 안 들어와요 — 우리 앱이 명확하게 뭘 하는 건지부터."
화면이 89장까지 늘었다. 이 문서가 앞으로 무엇을 남기고 무엇을 접을지 정하는 기준이다. 새 기능은 아래 셋 가운데 하나를 더 쉽게 만들 때만 넣는다.

## 한 문장
**아이마다 빠진 앞 학년 셈을 찾고(점검), 선생님이 그 아이에게 그것만 주고(보충), 아이는 매일 조금씩 풀어 메운다(매일 연습).**

## 세 가지
| | 누가 | 하는 일 |
|---|---|---|
| 1. 점검 | 아이가 풀고 선생님이 봄 | 종이 점검지와 **같은 문제 · 같은 판정**을 화면에서도 푼다. 한 번에 12문제(약 8분) · 남으면 다음 시간에 이어서. 끝나면 바로 반 표에 들어감 |
| 2. 반 표 → 보충 주기 | 선생님 | 표 한 장에서 "이 아이는 이게 부족하네"를 보고 단추 한 번으로 보충을 준다(화면 또는 종이 연습지) |
| 3. 매일 연습 | 아이 | 들어오면 단추 하나. 선생님이 준 것 → 매일 연습 5분 순서로 앱이 이어 줌 |

선생님이 아무것도 주지 않아도 매일 연습은 그 아이의 부족한 기능으로 채워진다(선생님이 병목이 되지 않게). 선생님이 준 보충은 맨 앞으로 온다.

## 아이 화면 — 누를 것은 하나
- 들어오면 큰 단추 하나 [오늘 할 것 시작]. 순서는 앱이 정함: ① 선생님이 낸 점검 ② 선생님이 준 보충 ③ 매일 연습(섞은 10문제 · 다시 볼 것 포함).
- 틀리면 그 자리에서 [풀이 보기] → 한 단계에 한 문장 풀이 → 같은 꼴 하나 더(지금 '판자 고치기' 네 단계가 여기로 들어옴).
- 끝나면 사실 한 줄: "12문제 중 10개 맞혔어요. 지난번엔 8개."
- 머리 탭 넷(오늘 · 스테이지 · 이야기 · 거꾸로)은 없앤다.

## 선생님 화면 — 표 한 장
- 줄 = 기능(맞춤 연습지 카드와 **같은 이름** · 가로 글씨) · 칸 = 아이 번호 · 표시는 셋: ○ 됨 · △ 흔들 · ✕ 부족(빈칸 = 아직 안 봄).
- 줄 끝: "부족 3명(2 · 4 · 5번) [보충 주기]". 번호를 누르면 그 아이의 부족한 것 목록 + [보충 주기].
- 보충 주기 = 화면(아이의 '선생님이 준 것'에 들어감) 또는 종이(맞춤 연습지).
- 맨 위 한 줄: 낸 점검 · 다 푼 아이 n명.
- 나머지(같은 생각끼리 · 10분 카드 · 이야기 다리 · 주간 그래프 · AI에게 묻기 · CSV · 백업)는 [더 보기] 안으로.

## 말 바꾸기 — 비유 말고 뜻 그대로
| 지금 | 바꿈 |
|---|---|
| 구보 | 매일 연습 |
| 준비 다리 | 점검 |
| 판자 · 고칠 판자 | 기능 · 부족한 것(아이 화면: 연습할 것) |
| 다듬기 정확 → 빠르게 → 오래 | 없앰. 표시는 됨 · 흔들 · 부족. 며칠 뒤 다시 보기는 매일 연습 안에서 저절로 |
| 내 선 · 선이 어디로 가나 | "지난번 8개 → 이번 10개" |
| 늘고 줄고 모이고 견주는 이야기 | 이야기 문제는 보충 갈래 하나로. 이름은 "늘어나요 · 줄어요 · 합쳐요 · 견줘요" 같은 동작 말 |
| "윗자리에서 10을 받아내려 12 − 9를 해요" | "2에서 9는 뺄 수 없어요 → 십의 자리에서 10을 가져와요 → 2가 12가 돼요 → 12 − 9 = 3" + 세로셈 그 자리에 표시 |
| "내 선에 점 하나가 더 생겼어요 …" | "10문제 중 7개 맞혔어요. 지난주는 6개." |

아이 말은 사실과 다음 할 일만. 앱이 자기 화면을 설명하는 말(선은 주마다 오르내려요 등)은 쓰지 않는다.

## 11-05 짚은 것 → 고칠 것
1. 구보 · 내 선 · 오래 가 · 이야기 이름 — 비유가 겹쳐 뜻이 안 보임 → 위 표대로.
2. 준비 다리 36문제 — 길다. 짐작 고르기까지 한 문제 30~40초면 36문제는 20분이 넘는다 → 한 번에 12문제, 남으면 이어서. '길게 36' 없앰.
3. 풀이 화면 배치(세 칸 · 오른쪽이 비어 있음) → 위: 문제 · 가운데: 세로셈 크게(단계마다 그 자리에 표시) · 옆: 모형 · 아래: 말풍선 한 문장 + 단추.
4. 받아내림 · 받아올림 풀이 글 — 절차 말만 있고 개념(36 = 20 + 16)과 안 이어짐 → 모형에서 바뀐 것과 식을 한 문장씩 잇는다.
5. 칸 × 아이 표의 세로 글씨 → 뒤집기(줄 = 기능 · 가로 글씨).
6. 종이 점검지를 화면에도 똑같이 → 같은 문제 · 같은 판정 · 결과 바로 표에.

## 남기는 화면(89 → 약 12)
- 아이: 들어가기 · 시작 · 문제 풀기 · 풀이 보기 · 끝
- 선생님: 반 만들기 · 반 표 · 아이 한 명 · 보충 주기 · 점검 내기 · 카드 인쇄
- 종이: 점검지 · 맞춤 연습지
- 스테이지 · 거꾸로 · 주간 그래프 · 같은 생각끼리 · 10분 카드는 지우지 않고 메뉴에서만 뺀다(필요하면 되살림).

## 차례(11-07 진행 — 교사 '로그인하면 카드 셋으로 뭘 할지 명확히')
1. 말 바꾸기 + 받아내림 · 받아올림 풀이 글 · 풀이 화면 배치
2. 선생님 반 표 뒤집기 + 보충 주기
3. 아이 홈 단추 하나 + 선생님이 준 것 + 매일 연습
