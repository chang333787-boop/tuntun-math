# 튼튼 수 다리 (tuntun-math)

한 반의 모든 아이가 **자기 수 다리의 빈 판자(선수 개념)**를 스스로 알아보고 고쳐 지금 배우는 단원을 따라가게 하고, 교사는 반 아이 모두의 빈 판자를 한 화면에서 보고 묶어서 가르치는 초등 수학 앱.

- 아이 스스로 — 내 수 다리 지도 · 오늘 할 일 · 풀기 전 자신감 → 푼 뒤 견주기(메타인지) · 판자 고치기(시범 → 함께 → 혼자 → 확인) · 스테이지 다듬기(정확 → 빠르게 → 오래) · 오늘의 구보 · **막힌 문제 거꾸로 찾기** · 이야기 다리(문장제 걸음 넷 · 읽어 주기) · 이번 주 점검(내 선)
- 교사 점검 — 기기 적응형(관문 → 막힌 곳만 아래로) 또는 종이 · 틀린 답 숫자로 가능한 원인 · 종이 결과를 아이 기록에 가져오기
- 다같이 수업 — 오늘 단원의 준비 다리를 아이마다(길이 고르기) · '지금 반' 띠 · 실시간 판 · 같은 생각끼리 · 같은 판자끼리 묶음 · 10분 소집단 카드 · 선이 어디로 가나 · CSV(번호만) · AI에게 물어보기(근거 글 복사)
- 캐릭터: 다리를 놓는 비버 **튼튼이**

이름은 저장하지 않아요(반 코드 + 번호). 주소: https://chang333787-boop.github.io/tuntun-math/ · 목표와 설계: [docs/goal.md](docs/goal.md) · 다음 차례: [docs/next.md](docs/next.md) · 근거: [docs/evidence.md](docs/evidence.md)(논문 · 국가 안내서 약 140편 · 설계 요소마다 근거와 강도)

교육과정 대응은 2022 개정 수학과 성취기준을 기준으로 하며, 차시 이름은 이 앱이 붙인 이름입니다(특정 출판사 교과서 · 지도서와 무관).

## 폴더
| 폴더 | 하는 일 |
|---|---|
| `engine/` | 엔진 — 1~6학년 수 · 연산 · 관계 229차시 선수 그물(`lessons/`) · 문항 만들기 · 틀린 답 숫자로 틀린 방법 다시 계산(`errors.js`) · 문장제 구조(`words.js`) · 같은 숫자로 쪼갠 풀이(`practice.js`) |
| `paper/` | 종이 점검(교사) — 선별 점검지 → 틀린 문제만 누르기 → 가능한 원인 · 여기서부터 → 확인지 · 보충지 · 다시 보기 · 반 표 |
| `app/` | 아이 · 교사 기기 앱 — 근거와 설계 요소 대응은 [docs/evidence.md](docs/evidence.md) · 시범 운영 [docs/pilot.md](docs/pilot.md) |
| `tests/` | 엔진 시험(`npm test`) · 고리 시험 `npm run sim` · 앱 시험 `npm run test:app` · 준비 다리 시뮬레이션 `npm run sim:prep` · 배포 주소 한 바퀴 `node tests/e2e/live.cjs` |

빌드 과정 없음(정적 파일). 로컬에서 보기: `npm run serve` → http://localhost:8030/app/ (종이 점검 /paper/) · 코드를 고치면 `node tools/ver.mjs`(기기 캐시 새로 받기)
