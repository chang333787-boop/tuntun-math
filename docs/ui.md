# 화면 다듬기 설계 한 쪽 (UI-1 · 11-01)

선생님 물음: "화면이 교육용 느낌 나? ui ux 최적화해줘"
범위: 보이는 것만(app/css/app.css · 마크업 조금). 판정 · 흐름 · 저장 로직은 그대로.
전 · 후 사진: 크롬북 1366×768 · 폰 390×844 — 아이 43장면 · 선생님 8장면(시험 반 ZZ로 찍고 지움).

## 1. 지금 화면의 문제

### 아이 눈(4학년)
1. **어디쯤인지 모름** — 준비 다리 점은 묶음마다 다시 시작(6칸)이고 숫자가 없음. 판자 고치기는 시범 → 같이 → 혼자 → 확인 가운데 어디인지 표시가 없음(혼자만 말풍선에 0/3).
2. **맞음 · 틀림이 색으로만** — 초록 · 분홍 테두리뿐. 흑백 인쇄 · 색약에서 안 보임.
3. **누를 곳이 여럿** — 꽉 찬 청록 단추(스테이지 · 이야기 다리 · 다듬기)가 주황 주 단추와 같은 무게. 점검 끝 화면엔 꽉 찬 단추가 다섯. 잠긴 '다 풀었어요'가 옅은 주황이라 눌러야 할 것처럼 보임.
4. **카드 속 카드** — 고치기 화면은 카드 안에 그림자 있는 문제 카드가 또 있음.
5. **말풍선 안 큰 수식** — 비교하기 '맞게 푼 건 73 + 39 = 112 이에요'에서 수식이 44px 한 줄을 통째로 차지해 말이 세 동강.
6. **작은 누를 곳** — '답 보기'(23px) · '이 기기에서 나가기'(23px) · '판자 이름 보기' 접기(38px) · '읽어 주기'(36px).
7. **자잘한 것** — 이유 고르기 글이 가운데 정렬 · 넘어간 문제에도 '틀림' 상자 · 들어가기 전 머리띠에 빈 알약 · 튼튼이 크기가 화면마다 60~84px.

### 선생님 눈(수업 중 3초)
1. **반 화면 맨 위 조작판이 무거움** — 고르기 둘 + 단추 넷 + 작은 단추 셋이 세 줄(1366에서 340px). '지금 반'이 첫 화면 가운데까지 밀림.
2. **'지금 반'에서 0명 줄과 사람 있는 줄이 같은 무게** — 눈이 '없음'을 다섯 번 읽음.
3. **'먼저 봐 줄 아이'가 다른 카드와 같은 모양** — 가장 급한 카드인데 눈에 안 띔.
4. **아이 자세히의 지도 메모** — 글 칸이 21px · 고르기 칩이 흩어짐 · 구역(h3) 사이 경계가 없어 긴 한 장.
5. **대비 미달 두 곳** — 카드 문제의 연한 답(3.2:1) · 아이 화면의 안 딴 표 · 요일 글자(2.8:1).

## 2. 바꿀 원칙
1. **한 화면 한 일 · 꽉 찬 단추 하나** — 주황 꽉 찬 단추 = 지금 할 일 하나. 청록은 테두리 단추(다음 갈래) · 나머지는 흰 단추.
2. **진행은 늘 같은 자리(문제 카드 오른쪽 위)에 점 + 숫자** — 길면(12개 넘음) 막대 + 숫자. 준비 다리는 판 전체(많아야 18 · 24 · 36문제). 고치기는 카드 맨 위에 걸음 칩 넷(이야기 다리와 같은 모양).
3. **맞음 ✓ · 틀림 ✕ 를 모양으로** — 되먹임 상자 왼쪽 동그라미 · 틀린 단계 · 막대 틀 · 보기에. 넘어간 문제는 표시 없이(솔직한 모름은 틀림이 아님).
4. **튼튼이는 카드 왼쪽 위 같은 자리 · 같은 크기**(72px · 폰 56px). 문제를 푸는 동안은 나오지 않음(눈이 문제에만).
5. **누를 곳 48px 안팎** — 아이 화면 단추 44px 이상(주 단추 58px) · 글 링크도 누를 높이 44px.
6. **선생님 화면은 위계: 지금(누구) → 왜 → 표 → 카드** — 조작판은 한 줄 + 작은 단추 한 줄. 정보는 빼지 않고 자리만 옮기거나 연하게.
7. **움직임은 의미 있는 것만** — 되먹임 상자가 160ms 나타남 · 틀린 입력 흔들기(있던 것). prefers-reduced-motion이면 둘 다 끔.
8. **팔레트 그대로** — 종이 교과서 바탕 · 나무 · 청록 · 주황. 바꾼 글자색은 대비를 잼(작은 글 4.5 이상 · 큰 글 3 이상).

## 3. 글꼴
- 본문 · 수식 · 선생님 화면은 지금 시스템 글꼴(Noto Sans KR · 애플 SD 고딕 · 맑은 고딕) 그대로.
- **제목만 둥근 글꼴 하나 — Google Fonts 'Jua'(한 굵기 400)**: 머리띠 이름 · 아이 홈 카드 제목 · 처음 화면 고르기 두 칸에만(할 일 제목엔 '82 + 96 = □ 같은 문제'처럼 수식이 섞여 시스템 글꼴 그대로).
  - 까닭: 아이가 가장 자주 보는 홈에서 '아이용 · 학습용'이 첫눈에 보이게. 둥글고 굵은 한 굵기라 제목에만 쓰면 유치하지 않음. 수식 · 문제 글에는 쓰지 않음(숫자 모양이 시스템 글꼴과 달라지면 헷갈림).
  - 안 깨지게: 렌더를 막지 않는 방식(media=print → onload)으로 읽음 · display=swap · 없으면 시스템 글꼴 굵게(700)로 · font-synthesis:none(가짜 굵기 X) · 인쇄 화면엔 안 씀.
  - 한글 글꼴은 Google이 글자 조각으로 나눠 보내 쓰는 글자만 받음(첫 화면 제목 몇 조각).

## 4. 화면별로 바꿀 것
| 화면 | 바꿀 것 |
|---|---|
| 공통 | 청록 단추 → 테두리 단추 · 잠긴 주 단추는 회색 · 머리띠 빈 알약 숨김 · 튼튼이 크기 통일 · 말풍선 속 수식은 글줄 크기로 · 글 링크 누를 높이 44px · 되먹임 ✓ ✕ · 되먹임 상자 160ms 나타남 |
| 문제 카드(준비 · 다듬기 · 구보 · 점검 · 확인) | 오른쪽 위 진행 = 점 + '3 / 10'(길면 막대) · 준비 다리는 판 전체 진행 · '풀기 전에' 짐작 칸을 연한 바탕으로 묶어 '먼저 짐작 → 답' 두 걸음이 보이게 · 넘어간 문제는 ✕ 없이 |
| 홈 | 맨 위 할 일(주 단추가 있는 줄)을 주황 테두리로 · 접기 누를 높이 · 안 딴 표 · 요일 글자 대비 |
| 판자 고치기 | 맨 위 걸음 칩 넷(시범 · 같이 · 혼자 · 확인 — 지금 걸음 · 지난 걸음 ✓ · 폰은 지금 걸음만 이름) · 비교하기는 '혼자' 걸음 안 · 카드 속 카드 그림자 뺌 · 이유 고르기 왼쪽 정렬 · '다음' 단추 제자리 |
| 이야기 다리 | 점 옆 '2 / 6' · 막대 틀 맞음 ✓ · 아님 ✕ · '읽어 주기' 44px |
| 점검 끝 · 다듬기 끝 | 다듬기 단추 넷이 테두리 단추가 되어 '내 수 다리로' 하나만 꽉 참 · 틀린 문제 줄 ✕(테두리 동그라미) · 넘어간 줄은 점선만 |
| 선생님 반 화면 | '먼저 봐 줄 아이'를 '지금 반' 위로(누구에게 갈지가 첫 화면에) · 조작판 = [단원 · 길이 · 오늘 단원으로 열기] 한 줄 + [새로 보기 · CSV · 종이 결과 · 카드 · 이름 · 안내] 작은 단추 한 줄 · '지금 반' 0명 줄은 연하게 · '선생님과 같이' 줄은 바탕색 · '먼저 봐 줄 아이' 카드 테두리 강조 + 이름 크게 + 사람 수 · TV 단추 36px |
| 선생님 처음 | 주 동작(새 반 · 다른 기기 반) 한 줄 + 인쇄물 셋은 작은 단추 줄 |
| 아이 자세히 | 구역마다 위 경계선 · 지도 메모 칩 줄 · 글 칸 44px |
| 10분 카드 · 안내 | 카드 문제 옆 연한 답 대비 3.2 → 4.8 · 인쇄 그대로 |

## 5. 하지 않은 것
- 아이 화면에 오개념 이름 · 순위 · 친구 비교 · 학년 X(그대로).
- 그라데이션 · 유리 · 빛 번짐 · 반짝이 · 떠다니는 장식 X. 새 이모지 X. :has() X.
- 문제 화면에 튼튼이를 새로 넣지 않음(풀 때는 문제만 · 시작 · 끝 · 고치기 안내에서만 말함).
