# 튼튼 수 다리 (tuntun-math)

한 반의 모든 아이가 **자기 수 다리의 빈 판자(선수 개념)**를 스스로 알아보고 고쳐 지금 배우는 단원을 따라가게 하고, 교사는 반 아이 모두의 빈 판자를 한 화면에서 보고 묶어서 가르치는 초등 수학 앱.

- 아이 스스로 — 내 수 다리 지도 · 오늘 할 일 · 풀기 전 자신감 → 푼 뒤 견주기(메타인지)
- 교사 점검 — 기기 적응형(관문 → 막힌 곳만 아래로) 또는 종이 · 틀린 답 숫자로 가능한 원인
- 다같이 수업 — 오늘 단원의 준비 다리를 아이마다 · 실시간 판 · 같은 빈 곳끼리 묶음
- 캐릭터: 다리를 놓는 비버 **튼튼이**

이름은 저장하지 않아요(반 코드 + 번호). 목표와 설계: [docs/goal.md](docs/goal.md)

교육과정 대응은 2022 개정 수학과 성취기준을 기준으로 하며, 차시 이름은 이 앱이 붙인 이름입니다(특정 출판사 교과서 · 지도서와 무관).

## 폴더
| 폴더 | 하는 일 |
|---|---|
| `engine/` | 엔진 — 1~6학년 수 · 연산 · 관계 229차시 선수 그물(`lessons/`) · 문항 만들기 · 틀린 답 숫자로 틀린 방법 다시 계산(`errors.js`) · 문장제 구조(`words.js`) · 같은 숫자로 쪼갠 풀이(`practice.js`) |
| `paper/` | 종이 점검(교사) — 선별 점검지 → 틀린 문제만 누르기 → 가능한 원인 · 여기서부터 → 확인지 · 보충지 · 다시 보기 · 반 표 |
| `app/` | 아이 · 교사 기기 앱(만드는 중) |
| `tests/` | 엔진 시험(`npm test`) · 고리 시험은 `npm run sim` |

빌드 과정 없음(정적 파일). 로컬에서 보기: `npm run serve` → http://localhost:8030/paper/
