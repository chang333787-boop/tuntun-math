## 선생님께 한 쪽

1. **지금 얼마나 덮나 — 2022 성취기준 121개 가운데 있음 61 · 일부 13 · 없음 47(일부를 반으로 치면 56%).**
   - 영역별: 수와 연산 **98%**(42개 중 41) · 변화와 관계 **55%** · 도형과 측정 **32%** · 자료와 가능성 **21%**.
   - 차시로 세면 지금 262차시 / 다 지었을 때 약 371차시(조사 문서가 제안한 빠진 차시 109를 더한 값) = **71%**. 학년으로는 **4학년이 52%로 가장 낮다**(각도 · 삼각형 · 사각형 · 다각형 · 이동 · 그래프 둘이 다 4학년).
2. **'영역 간 계열'은 우리 그물에 한 방향으로만 있다.**
   - 차시 앞 줄(pre) 859개 가운데 영역을 건너는 줄은 106개다. **106개 모두 '수와 연산 → 다른 영역'(계산 선수)이다.** 거꾸로 가는 줄(측정 → 분수 같은)은 하나뿐이고, 도형 · 관계 · 자료끼리 잇는 줄은 0개다.
   - E9가 찾은 영역 간 계열 31줄과 견주면: 이어짐 8 · 일부 4 · 양 끝이 다 있는데 안 이어짐 4 · 끝 차시가 아직 없음 12 · 같은 교구로 잇는 줄 3.
   - **지금 바로 넣을 빠진 다리는 둘**이다: `2-2-4:4`(1시간 = 60분) → `3-2-4:4`(1시간의 몇 분의 몇) · `6-1-3:7`(몫을 소수로) → `6-1-4:4`(비율을 소수로). 나머지 넷은 '선수'가 아니라 '같은 생각'이라 앞 줄 대신 옛 개념 다리(bridges.js)로 잇는 게 맞다(§3-5).
3. **추천 차례**: ⓪ 계열 다리 · 성취기준 표를 코드로 → ① 자료와 가능성 단계 1 마무리(3차시) → ② 활동판 바닥 + 수 활동판 여섯(지금 수와 연산 약 170차시에 '해 보기') → ③ 측정 활동판 + 측정 빈칸 20차시 → ④ 자료와 가능성 나머지 17차시 + 그래프 · 실험 · 평균 판 → ⑤ 변화와 관계 빈칸 8차시 → ⑥ 도형 61차시(평면 → 이동 · 대칭 → 입체). **지금 차시 다듬기는 단계마다 끝에 한 묶음씩** 넣는다.
   - 까닭 한 줄: 싸고 모든 단계의 잣대가 되는 것(⓪) → 이미 연 묶음 닫기(①) → 지금 아이들이 쓰는 차시에 가장 넓게 닿고 근거가 가장 단단한 조작(②) → 조작과 진단이 가장 자연스럽게 겹치는 측정(③) → 진단 힘은 약하고 그림 · 판 비용이 가장 큰 도형은 맨 뒤(⑥).
4. **지킬 원칙 셋**: ① 진단은 지금처럼 **종이로 인쇄해 풀 수 있는 문제**로만 한다 — 조작 결과로 판정하거나 반 표 칸을 바꾸지 않는다. ② 조작은 배우기 맨 앞 '해 보기'(1~3분 · 건너뛰기) · 도움 사다리 · 선생님 판 · 활동 상자에만 둔다. ③ 앞 줄(pre)에는 '이걸 못 하면 저걸 못 푼다'만 넣는다. 영역 간 '같은 생각'은 옛 개념 다리나 같은 활동판으로 잇는다.
5. **정할 것(추천안 있음 · §4-5)**: ① `6-2-2` 충돌 → **지금 6-2-2(소수의 나눗셈)는 그대로 두고, 공간과 입체를 `6-2-3`으로**(화면은 단원 번호를 보이지 않고 이름만 보여서 아이 · 선생님 눈에는 충돌이 안 보임 · 기록이 끊기지 않음) ② 도형을 반 표 진단에 넣는 방식 ③ 해 보기 기록을 반 표에 보일지 ④ 1~2학년 국정 단원 번호 확인 ⑤ 4-1-6:3 'n째' 꼴 ⑥ 반 표 기본 보기.

**확인 수준**

**덮음**: 있음 = 이 성취기준의 '문제로 잴 수 있는 몫'이 차시로 있음 · 일부 = 그 몫의 일부만 있음 · 없음 = 차시가 없음(SKIPPED로 이름만 있는 것도 없음).
**빠진 것**: 덮음이 '없음 · 일부'면 문제로 재는 내용에서 빠진 것, '있음'이면 아직 없는 조작(해 보기)이다.
**형태**: 문제 = 문제로 진단하고 조작은 없어도 됨(도움 그림이면 충분) · 둘 다 = 문제로 진단 + 배우기 앞 '해 보기' · 조작 중심 = 활동판이 배움의 중심이고 문제는 보기 고르기 몇 개뿐(진단 힘 약함) · 활동만 = 문제로 재지 않음(SKIPPED · 활동 상자).

### 4-3 지킬 원칙

**가. 진단과 조작**
1. **진단은 종이로 인쇄해 풀 수 있는 문제로만** 한다(what.md '종이와 같은 문제 · 같은 판정'). 쌓기나무 개수도 정적 겨냥도로 풀 수 있게 낸다. 판을 움직여야만 풀리는 문제는 점검에 넣지 않는다.
2. **조작 결과는 판정에 넣지 않는다**(manip_plan §2 · E8 R25 — 엄격한 연구일수록 효과가 작아 앱 안 '해냈어요'를 학습 증거로 보지 않음).
3. **읽기형 판(자 · 각도기 · 시계 · 저울 · 눈금 그릇)** 은 같은 그림의 정적판이 문제로, 움직이는 판이 해 보기로 쓰인다. 판에서 처음부터 값이 보이지 않게 하고 0점 · 중심 자석을 끈다(E10 ④ 5 · 12).
4. 원인(오답 꼴) 이름은 조사 문서에 근거 줄이 있을 때만 붙인다. 도형 성질처럼 근거가 없으면 맞음 / 틀림 + 같은 꼴 하나 더(evidence.md '두 문항 이상에서 되풀이될 때만').

**나. 기록 · 반 표**
1. 문제로 재는 차시(도형 포함)는 지금처럼 기록되고 반 표 칸(○ · △ · ✕)에 들어간다.
2. **해 보기 기록은 차시마다 '해 본 날' 하나만** 남기고 반 표 칸을 바꾸지 않는다. 아이 자세히에 한 줄로만 보인다. 끌기 하나하나 같은 사건 기록은 남기지 않는다(한 학기 요약 9~15천 자 · 서버 상한 3만 · semester 시험 문턱 2만 4천 — now.md).
3. '활동만' 성취기준과 SKIPPED 활동(E9 제안 7 · E7 자료 모으기 등)은 반 표에 줄이 없다. 화면에는 지금처럼 '이 배움은 문제로 재지 않아요'.

**다. 화면 흐름 — 해 보기 → 보기 → 풀기**
1. 배우기: **해 보기**(판 · 1~3분 · 목표 한 줄 → 첫 수를 같이 → 아이 차례 · 건너뛰기) → **보기**(시범 그림 — 판과 같은 색 · 같은 자리 · '아까 셈돌 8개가 여기 8') → **풀기**(함께 → 혼자 → 확인 3문제). 새 화면이 아니라 배우기 안의 칸이다.
2. 도움 사다리: ① 떠올리기 → **직접 해 볼까요?**(같은 판 · 이 문제의 수) → ② 한 단계씩 → ③ 처음 문제 다시.
3. **점검 · 매일 연습에는 판을 두지 않는다**(점검 8분 · 매일 연습 5분을 지킴).
4. 1~4학년은 해 보기를 펼쳐 두고, 5~6학년은 접어 둔다(한 번 눌러 열기 · E8 R23).
5. 판 안은 밋밋하게(단색 · 숫자 적힌 동전 · 캐릭터 X — E8 R6) · 판 옆 식 줄이 함께 바뀐다(R1) · 자유 놀이로 시작하지 않는다(R19) · 판이 목표를 스스로 판정하고 어긋난 곳을 판 위에 보인다(R17).

**라. 범위 — 교육과정이 막은 줄**: 사각형 포함 관계 X · 원그래프 각도 계산 X · 이동은 한 번만 · 점의 이동은 격자 칸 · cm까지 · 각 그리기 X(재기 · 어림만) · 각뿔 · 원뿔 전개도 X · km↔cm · t↔g · cm²↔km² 같은 지나친 환산 X · 원 · 겉넓이 · 부피의 복잡한 계산은 계산기 또는 식 고르기(E9 §2-4 · E5 §1-2).

**마. 차시 · id**: 차시 id는 **기록의 열쇠**이지 교과서 번호를 보이는 이름표가 아니다 — 한 번 쓴 id는 다른 내용에 다시 쓰지 않는다. 새 차시는 성취기준 코드를 하나 이상 단다.

**강점을 지키는 장치 다섯(한 줄씩)**
1. 성취기준 표 + 시험(⓪) — 넓혀도 무엇이 비고 무엇이 겹치는지 숫자로 보인다.
2. 앞 줄 = 선수만(§3-5) — 거꾸로 찾기의 정확성.
3. 진단 = 종이와 같은 문제(§4-3 가) — 조작이 판정을 흔들지 않는다.
4. 판 = 배우기 안의 칸(§4-3 다) — 아이 단추 하나 · 화면 수가 늘지 않는다.
5. 새 차시는 고리 시험을 넘긴 뒤에만 점검에 — 시뮬레이션이 보장하는 판정 품질을 그대로 둔다.
