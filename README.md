# 튼튼 수 다리 (tuntun-math)

아이마다 빠진 앞 학년 셈을 **찾고**(점검), 선생님이 그 아이에게 **그것만 주고**(보충), 아이는 **매일 조금씩 풀어** 메운다(매일 연습). 정본: [docs/what.md](docs/what.md)

- 아이 화면 = 카드 셋 — **① 점검**(오늘 단원 점검 · 선생님 점검지 · 이번 주 점검) · **② 연습할 것**(선생님이 준 문제 · 튼튼이와 배우기: 시범 → 같이 → 혼자 → 확인) · **③ 매일 연습**(섞어서 3~5분 · 1 · 3 · 7일 다시 보기)
- 선생님 화면 = 카드 셋 — **① 점검 내기**(오늘 단원 · 종이와 같은 점검지 · 이번 주) · **② 반 표**(줄 = 기능 · 칸 = 아이 번호 · ✕ 부족 · △ 흔들 · ○ 됨) · **③ 보충 주기**(기능 · 아이 · 문제 수 → 아이 화면 또는 같은 문제 종이)
- 그 밖에(더 보기): 같은 생각끼리 · 같은 칸을 배울 아이끼리 10분 카드 · 이야기 문제 · 맞춤 연습지 · 종이 결과 가져오기 · CSV(번호만)
- 캐릭터: 다리를 놓는 비버 **튼튼이**

아이 이름은 서버에 올리지 않아요(서버엔 반 코드 + 번호 · 이름은 선생님 기기에만). 주소: https://chang333787-boop.github.io/tuntun-math/ · 목표와 설계: [docs/goal.md](docs/goal.md) · 다음 차례: [docs/next.md](docs/next.md) · 근거: [docs/evidence.md](docs/evidence.md)(논문 · 국가 안내서 약 140편 · 설계 요소마다 근거와 강도)

교육과정 대응은 2022 개정 수학과 성취기준을 기준으로 하며, 차시 이름은 이 앱이 붙인 이름입니다(특정 출판사 교과서 · 지도서와 무관).

## 폴더
| 폴더 | 하는 일 |
|---|---|
| `engine/` | 엔진 — 1~6학년 수 · 연산 · 관계 229차시 선수 그물(`lessons/`) · 문항 만들기 · 틀린 답 숫자로 틀린 방법 다시 계산(`errors.js`) · 문장제 구조(`words.js`) · 같은 숫자로 쪼갠 풀이(`practice.js`) |
| `paper/` | 종이 점검(교사) — 선별 점검지 → 틀린 문제만 누르기 → 가능한 원인 · 여기서부터 → 확인지 · 보충지 · 다시 보기 · 반 표 |
| `app/` | 아이 · 교사 기기 앱 — 근거와 설계 요소 대응은 [docs/evidence.md](docs/evidence.md) · 시범 운영 [docs/pilot.md](docs/pilot.md) |
| `tests/` | 엔진 시험(`npm test`) · 고리 시험 `npm run sim` · 앱 시험 `npm run test:app` · 준비 다리 시뮬레이션 `npm run sim:prep` · 배포 주소 한 바퀴 `node tests/e2e/live.cjs` |

빌드 과정 없음(정적 파일). 로컬에서 보기: `npm run serve` → http://localhost:8030/app/ (종이 점검 /paper/) · 코드를 고치면 `node tools/ver.mjs`(기기 캐시 새로 받기)
