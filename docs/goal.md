# 목표 다시 세우기 (10-31 · 교사)

## 교사가 말한 문제
- 한 반 27명, 아이마다 약점이 다름(누구는 덧셈, 누구는 구구단).
- 교과서는 이전 학년이 마스터됐다고 가정하고 나아감 → 잘하는 아이는 편하게 새것을 배우고, 못하는 아이는 옛것도 모른 채 새것까지 → 격차가 벌어짐.
- 문장제는 문장을 나눠 보는 구조적 문해력과 문제 유형에 익숙하지 않은 아이가 많음.
- 교사는 27명의 약점을 다 보고 싶어도 시간이 없음.
- 아이는 '몇 학년 몇 단원 풀기'가 아니라 **내 기본 약점을 인정하고, 반복해서 다음 단계로 가는 메타인지**를 길러야 함.
- 시중 도구: 선수학습을 보는 것이 없고, 아이의 치밀한 자기 관리 + 교사가 아이마다 빈 개념을 한눈에 보는 것은 없거나 제한적.

## 목표(한 문장)
**한 반의 모든 아이가 자기 수 다리의 빈 판자를 스스로 알아보고 고쳐 지금 배우는 단원을 따라가게 하고, 교사는 27명의 빈 판자를 한 화면에서 보고 묶어서 가르친다.**

## 세 쓰임(모드)
1. **아이 스스로 — '내 수 다리'**: 반 코드 + 번호로 들어감(이름 없음). 내 다리 지도(판자 = 차시 · 튼튼 / 흔들 / 빈) → 오늘 할 일 10~15분(고칠 판자 → 같은 숫자 쪼갠 풀이 → 연습 → 다시 보기) · **풀기 전 자신감 표시 → 푼 뒤 견주기**(메타인지) · '내가 고친 판자' 기록 · 고를 수 있는 다음 판자(추천 + 까닭).
2. **교사 점검(시험)**: 교사가 반 전체나 고른 아이에게 점검을 냄 → 아이 기기에서 **적응형**(관문 → 막힌 곳만 아래로 · 15~20분) 또는 **종이**(지금 것) → 결과가 교사 화면으로 바로.
3. **다같이 수업**: 교사가 '오늘 단원'(예: 4-2 분수의 덧셈)을 열면 아이마다 **그 단원의 준비 다리**(선수 차시 중 빈 것만)를 수업 첫 5~10분에 각자 풂 · 교사 화면에 실시간 판(누가 무엇을 고치는 중) · 같은 빈 곳끼리 묶음 → 작은 무리 지도.

## 교사 화면
반 × 차시 한눈 보기(오늘 단원의 선수 줄기부터) · 같은 '여기서부터'끼리 묶음 · 아이마다 처음 → 지금 · 문장제 구조 프로필 · 가정 글 · 기기 없는 아이용 종이.

## 문장제 — '이야기 다리'
문장을 나눠 보기(누가 · 아는 것 · 묻는 것) → 막대 그림 고르기 → 식 → 계산. 같은 구조 작은 수 짝(구조 문제인지 계산 문제인지 가름) · 구조(더 생김 · 덜어 냄 · 비교 · 처음 수 · 묶음 · 몇 배 · 등분 · 포함)를 고루.

## 아이 앱 느낌
'튼튼이와 수 다리 건너기' — 딱딱한 교육 앱이 아니라 아이 앱(똑똑 수학탐험대처럼 친근하게). 보상은 **보이는 다리가 이어지는 것**과 고친 판자 배지(순위 · 비교 없음). 판타지 X(비버가 다리 놓는 현실 장치) · AI 슬롭 X(그라데이션 · 반짝이 X · 손그림 선화).

## 기존 자산과의 관계(새로 다 짓지 않음)
- 엔진: math-gaps(229차시 그물 · 적응형 단원 점검 · errors.js 원인 · words.js 문장제 · 쪼갠 풀이 · 세 단계 숙련)
- 오늘의 수학(RPG mathgap): 아이 탑 · 연습 · 막히면 아래로 · 빠르기 · 교사 화면 · Firebase 동기화 — **아이 스스로 모드의 80%가 이미 있음** → 새 저장소로 옮겨 일반화
- 튼튼 수 다리(sheets): 종이 점검 · 판정 · 확인지 · 보충지 · 다리 편지 · 고리 시험

## 첫 판(M1) → M2 → M3
- **M1** 새 저장소 · 반 코드 로그인 · 내 수 다리 지도 · 오늘 할 일(고칠 판자 연습) · 자신감 표시 · 교사 한눈 보기 · 기기 적응형 점검(종이 결과와 같은 판정)
- **M2** 다같이 수업(오늘 단원 준비 다리 · 실시간 판) · 이야기 다리
- **M3** 우리 반 27명 파일럿(빈 판자 해결률 · 다음 단원 성취) → 다른 반 배포
