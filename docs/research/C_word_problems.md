# C. 문장제 구조 읽기 — 「튼튼 수 다리」 '이야기 다리' 근거 (2026-10-31)

[n] = ④ 번호. 강도 상 = 메타분석·국가 안내서 '강함' / 중 = 큰 상관·소수 실험 / 하 = 기술·의견·간접 추론.

## ① 핵심 발견

1. **구조(스키마) 기반 지도는 효과가 있다 — 상.** IES 2021 안내서 권고 5 '강함': 18연구 1,751명, 자연수 문장제 g = 0.54 [0.43–0.65], 분수 문장제 g = 0.93 [9]. 학습 어려움 K-12 메타분석 33연구 g = 0.56 [0.40–0.72], **전이를 직접 가르친 스키마 확장형이 일반 SBI보다 컸다** [10][15][16]. 초등 52연구 네트워크 메타분석도 최강 조합에 SBI 포함 [11]. 2009 안내서도 '강함' [13].
2. **난이도는 연산보다 구조·문장이 만든다 — 상.** 69연구 메타분석: 미지수 위치·구조 유형·무관한 정보·현실 고려·어휘 불일치·단계 수가 관련(g = 0.39~4.26). 가장 어려운 것 = 처음(첫 자리) 모름·어휘 불일치·여러 단계. 친숙한 맥락과 연산 종류는 일반적으로 난이도를 설명하지 못함 [8].
3. **구조 분류 — 중(이론·기술, 널리 합의).** 덧·뺄 = 변화·합병(부분-전체)·비교 × 미지수 위치 [1][3][12]; 교사가 이 분류로 아이 생각을 배운 CGI 실험반 학생이 문제해결·자신감에서 앞섬 [2]. 곱·나눗 = 같은 묶음(동수누가)·배(곱셈 비교)·배열·곱집합 [5], 측정 동형·측정 곱 [4]; 나눗셈 = 등분제/포함제 [6][9]. 아이 모델(세기·거듭 더하기·곱셈)은 수 크기·말·구조에 따라 바뀜 [7].
4. **핵심어 전략은 해롭다 — 중.** 패널: 낱말-연산 연결을 가르치지 말 것 — 전체를 안 읽게 하고, 핵심어 없는 문제에서 막히고, 여러 단계에선 더 헷갈림('모두'인데 곱셈, '더'인데 뺄셈 예시 표) [9][12]. 실패 해결자는 수·관계어를 바로 옮기고 성공자는 상황 모델을 세움(대학생) [20]; 불일치 관계 문장에서 오류 증가 [21]; 3학년 112명도 '더'가 든 불일치 문제에서 식 정확도 하락 [23]; 시험 문항 214개에서 핵심어가 맞는 경우가 절반 미만 [22].
5. **문장제 어려움 ≠ 계산 어려움, 언어와 묶임 — 상.** 3학년 924명: 계산만 35·문장제만 33·둘 다 64명, 상관 .30~.49, 문장제 어려움은 언어와 연결 [24]. 문장제는 글 이해의 한 형태 + 문장제 고유 언어 [25]; 4학년 글 이해가 읽기 유창성·계산 통제 후에도 7·9학년 문장제 예측 [26]. **SBI에 언어 지도를 끼우면 더 오름**: 1학년 391명, 언어 포함 vs 대조 g = 1.75, 언어 없음 vs 대조 1.08, 둘 차이 0.47 [27].
6. **그림은 도식으로 — 일반 상, 막대 모델 자체 하~중.** 4~8학년 시각 표현 지도 '강함' [14]; 사물 그림보다 관계 도식이 성적과 관련 [19]; 꼼꼼한 그림 대신 단순 표시 [9]. 막대 모델은 틀 정리·사용 분석 [17]과 소규모 단일대상 연구 [18]뿐 — 무작위 대조 효과 크기는 못 찾음.
7. **작은 수 쌍둥이 진단 — 하(직접 검증 연구 없음).** 간접 근거: 두 어려움의 분리 [24]; 뉴먼 오류 분석에서 634명 6,595개 오류 중 읽기·이해·변환 40%, 부주의 약 30%, 계산 25% [28]; 패널도 계산이 막히면 "익숙한 수로 바꾸라" [9]. 단 수의 크기·종류가 연산 선택을 바꿈 [7][29].

## ② 설계 원칙

1. **구조 유형 표가 뼈**: 덧·뺄 3 × 미지수 3, 곱·나눗 4 × 등분/포함. 유형 이름은 연산 이름과 뗀다. [3][5][9][12]
2. **한 유형씩, 빈칸 없는 이야기 먼저** → 같은 이야기에서 수 하나 지우기. [9]
3. **미지수 위치 고루**(결과·변화·처음 / 큰·작은·차 / 묶음 수·묶음 크기). 처음 모름은 뒤쪽이되 꼭. [2][8][9]
4. **나눠 읽기 단계**: 읽기 → 무엇 이야기(밑줄) → 유형 이름 → 묻는 것 → 쓸·버릴 정보 → 그림 → 식 → 답 이름표. 익숙해지면 안내를 줄임. [9][12][28]
5. **유형별 막대 틀**: 부분-전체 한 막대, 비교 두 막대+차, 같은 묶음 칸 막대 — 식보다 먼저. [9][14][17][19]
6. **말 다리 내장**: 비교어·범주어(동물 = 개+고양이)·때·까닭어, 뒤집은 말 쌍(3살 많다 ↔ 3살 적다). [9][27]
7. **불일치 문제를 섞고** 틀리면 "어느 낱말이 속였나" 되짚기. [21][23][27]
8. **풀지 않고 유형만 맞히기** + 배운 유형 섞은 누적 복습. [9]
9. **넓히기 사다리**: 무관한 수 → 표·그림 속 정보 → 두 단계 → 낯선 낱말. [9][10][16]
10. **작은 수 쌍둥이**: 같은 구조 한 자리 수 문제를 붙여, 그것도 틀리면 구조 갈래·그것만 맞으면 계산 갈래로 다음 연습을 고름. 판정 아닌 갈래 고르기, 수 종류는 그대로. [7][9][24][28]
11. **오답 나침반은 단계로**: 이해·변환·계산 중 어디서 끊겼나. [28]

## ③ 하지 말 것

- 낱말→연산 표('모두 = 더하기', '남은 = 빼기', '씩 = 곱하기')를 가르치거나 힌트로 띄우기 [9][12][22]
- "빼기 문제"처럼 유형을 연산으로 부르기 [9][12]
- 결과 모름만 잔뜩 [8]
- 꼼꼼한 사물 그림, 답 확인용 장식 막대 [9][19]
- 핵심어 금지를 '낱말 무시'로 오해 — 관계어는 오히려 가르친다 [27]
- 친숙한 이야기면 쉬워진다고 기대(동기용은 괜찮음) [8]
- 쌍둥이 한 문항으로 '읽기 부진' 표시 — 근거 약함
