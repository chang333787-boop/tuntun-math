## 1. 이야기 다리(문장제) — 근거 가장 셈 + 선생님이 처음 말한 문제
- 근거: 구조(스키마) 지도 g 0.54 · 국가 안내서 '강함' · 언어 지도를 끼우면 더 오름 · 핵심어 표는 해로움 [C-9][C-10][C-27]
- 설계 한 쪽 먼저(아래 초안) → 확인 뒤 짓기
- 엔진 쪽 먼저 할 일(논란 없음): words.js 15구조를 구조 표(변화 · 합병 · 비교 × 모르는 자리 / 같은 묶음 · 몇 배 · 배열 × 등분 · 포함)에 맞춰 빈 칸 찾기 · 불일치 비교 문장 · 처음 수 모름 고루

### 이야기 다리 설계 초안(한 쪽)
1. **들어가는 곳**: 준비 다리 · 판자 고치기와 같은 고리 — 학년 문장제 점검(구조마다 2문제) → '이야기 판자' 칸이 비면 고치기
2. **한 문제 = 네 걸음**(익숙해지면 줄임): ① 무슨 이야기?(유형 고르기 — 그림 카드 셋: 더해짐/덜어짐 · 부분과 전체 · 비교) ② 무엇을 묻나?(문장에서 묻는 곳 누르기) ③ 막대 틀 채우기(유형별 정해진 틀 · 아는 수 끌어 놓기 · 모르는 칸에 ?) ④ 식 → 답(단위 이름표)
3. **판정**: 유형 · 막대 · 식 · 계산을 따로 — 어디서 끊겼는지(이해 · 변환 · 계산 [C-28])가 선생님 화면에 '이야기 구조 프로필'로
4. **고치기**: 같은 이야기에서 수 하나만 지우기 → 같은 구조 새 이야기 → 불일치 문제(‘더’가 있는데 빼기) 섞기 → 유형만 맞히기 섞어 복습
5. **작은 수 쌍둥이**: 같은 구조를 한 자리 수로 붙여 '구조에서 막혔나 · 계산에서 막혔나'로 **다음 연습 갈래만** 고름(판정에 쓰지 않음 — 근거 하)
6. **하지 않음**: '모두 = 더하기' 같은 낱말 표 · 연산 이름으로 부르는 유형 · 꼼꼼한 사물 그림
